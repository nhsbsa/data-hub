Overview

The Oracle-based report has been migrated to Power BI and redesigned to improve navigation, reporting performance, and access to data. This document provides a summary of key changes and where information can now be found within the new dashboard.

Key changes

Dashboard name change
Previous name New name
eOPS v3 - with Performer Data NHS England Ophthalmic Activity Report

Measure changes

New measures
Measure Description
Year on Year (YoY) Percentage difference between the current month and the same month in the previous year.
Claim value Calculated claim value for the selected claim.
Removed measures
Measure Reason
Claim ID Temporarily removed to improve dashboard performance. Planned for inclusion in future developments.
