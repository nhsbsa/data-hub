About this dashboard

There is a need for dental commissioners and providers to monitor the activity of dental providers both nationally and within a specific area. This helps make sure that services are commissioned effectively to maximise the benefit to patients.

To enable this, several dashboards are available within the eDEN system to allow users to access a range of dental data including detailed information extracted from the FP17.

This dashboard has been developed to provide eDEN users with the ability to extract data directly from the system in convenient data tables, to aid commissioners in the analysis of dental activity.

The dashboard provides information relating to Welsh dental activity at contract national level for all contracts within a specific Local Health Board for a range of different metrics, allowing users to quickly download data from the system.

Contact and feedback

If you have any queries regarding the data provided contact data services support. If you plan to publish the data include the name of the dataset for reference (this ensures that the figures are not misunderstood or misrepresented).
