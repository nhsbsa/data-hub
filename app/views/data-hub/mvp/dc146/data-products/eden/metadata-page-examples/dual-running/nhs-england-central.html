About this report

There is a need for dental commissioners and providers to monitor the activity of dental providers nationally and within a specific area. This helps make sure that services are commissioned effectively to maximise the benefit to patients.

To enable this, a series of dashboards are available within the eDEN system to allow users to access a range of dental data including detailed information extracted from the FP17.

This dashboard provides information on general and orthodontic dental activity for all contracts nationally. Data can be shown for all contracts or split by a selected ICB(s), on a monthly basis for the current financial year.

Financial information on payments made to dental contractors is also available within the dashboard. This includes data on non-delegated costs held at regional level which are not included in other eDEN dashboards.

A series of download tabs are also available within the dashboard to allow users to easily extract the information from the system.
