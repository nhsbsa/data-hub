About this report

There is a need for dental providers to monitor their activity and individual contracts within the provider and the performers within the individual contracts. This helps make sure that they are providing the services they are commissioned to deliver and maximise the benefit to patients.

To enable this, a dashboard is available within the eDEN system which allows users to access a range of dental data including detailed information extracted from the FP17.

The dashboard provides information relating to contract dental activity at contract and performer level for a range of different metrics, allowing users to visualise data within the system and quickly download data related to those metrics.

Contact and feedback

If you have any queries regarding the data provided contact data services support. If you plan to publish the data include the name of the dataset for reference (this ensures that the figures are not misunderstood or misrepresented).
