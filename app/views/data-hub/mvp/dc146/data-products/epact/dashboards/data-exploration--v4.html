Time frame:
24 months
{% endset %} {% set content_02 %}

Use this dataset to compare prescribing and dispensing activity over the latest 24 months. Choose this dataset when you need year-on-year comparisons or trends that require more than 12 months of data.

{% endset %} {% set header_03 %} Full history dataset
Time frame:
10 years
{% endset %} {% set content_03 %}

Use this dataset to analyse all available prescribing and dispensing activity. It includes data held under the data retention policy and supports long-term trend, strategic and market analysis.

{% endset %} {% set header_04 %} Full history dataset (BNF level)
Time frame:
10 years
{% endset %} {% set content_04 %}

Use this dataset to analyse prescribing costs at British National Formulary (BNF) presentation level instead of individual pack level. It contains less detail than the full history dataset. It may run faster when analysing large amounts of cost data and broad prescribing trends.

This dataset does not include available supplier information for:

  • prescribed drugs or appliances at BNF presentation level
  • dispensed drugs or appliances at BNF presentation level
{% endset %} {% set header_05 %} Monthly dispensing activities
Time frame:
10 years
{% endset %} {% set content_05 %}

Use this dataset to analyse monthly submissions from dispensing contractors, including pharmacy activity, reimbursement and remuneration.

The dataset includes data about:

  • dispensing organisations
  • dispensing fees
  • submission volumes
{% endset %} {% set header_06 %} PCA monthly and yearly
Time frame:
10 years
{% endset %} {% set content_06 %}

Use this dataset to analyse published prescribing and cost information from Prescription Cost Analysis (PCA). The data is aggregated and used in official national prescribing statistics.

{% endset %} {% set header_07 %} 12-month rolling dataset (provider level)
Time frame:
10 years
{% endset %} {% set content_07 %}

Use this dataset to analyse prescribing and dispensing activity using rolling 12-month totals. Data is grouped by commissioner or provider area. It can help you identify longer-term trends while reducing the effect of seasonal changes.

Analyse costs and volumes by:

  • commissioner or provider area
  • prescribing organisation attributes
  • dispensing organisation attributes
  • detailed prescribed drug or appliance attributes
  • detailed dispensed drug or appliance attributes
  • patient attributes
  • prescription form attributes
{% endset %} {% set header_08 %} 12-month rolling dataset (practice level)
Time frame:
10 years
{% endset %} {% set content_08 %}

Use this dataset to analyse prescribing and dispensing activity using rolling 12-month totals. Data is grouped by individual practice and local provider. It can help you monitor trends, compare patterns and reduce the effect of seasonal changes.

Analyse costs and volumes by:

  • practice-level prescribing organisation attributes
  • dispensing organisation attributes
  • detailed prescribed drug or appliance attributes
  • detailed dispensed drug or appliance attributes
  • patient attributes
  • prescription form attributes
